# Local macOS setup with oMLX

This path keeps summarization and TTS on your Mac. It uses oMLX for local inference, Gemma for short summaries, and Kokoro for speech.

## Install oMLX

```bash
brew tap jundot/omlx https://github.com/jundot/omlx
brew install omlx
brew services start omlx
```

oMLX serves an OpenAI-compatible API on `http://127.0.0.1:8000/v1` by default.

## Download recommended models

```bash
uvx hf download mlx-community/Kokoro-82M-bf16 \
  --local-dir ~/.omlx/models/Kokoro-82M-bf16

uvx hf download unsloth/gemma-4-E4B-it-UD-MLX-4bit \
  --local-dir ~/.omlx/models/unsloth/gemma-4-E4B-it-UD-MLX-4bit
```

Recommended defaults:

- TTS model: `Kokoro-82M-bf16`
- TTS voice: `af_heart`
- Summary model: `unsloth/gemma-4-E4B-it-UD-MLX-4bit`

## Configure Speakup

Create the default config if you do not have one yet:

```bash
speakup init-config
```

Then set `~/.config/speakup/config.jsonc` to use oMLX locally:

```jsonc
{
  "privacy": {
    "mode": "local_only",
    "allow_remote_fallback": false
  },
  "summarization": {
    "provider_order": ["omlx", "rule_based"]
  },
  "tts": {
    "provider_order": ["omlx", "piper", "macos"],
    "audio_format": "wav"
  },
  "providers": {
    "omlx": {
      "base_url": "http://127.0.0.1:8000/v1",
      "api_key_env": "OMLX_API_KEY",
      "summary_model": "unsloth/gemma-4-E4B-it-UD-MLX-4bit",
      "model": "Kokoro-82M-bf16",
      "voice": "af_heart"
    },
    "piper": {
      "auto_start": true,
      "data_dir": "~/.local/share/speakup/piper-voices",
      "model": "en_GB-alba-medium",
      "voice": "en_GB-alba-medium",
      "idle_timeout_seconds": 600
    }
  }
}
```

`OMLX_API_KEY` is optional for local oMLX. If unset, Speakup sends a local placeholder key.

## Verify

```bash
speakup \
  --summary-provider omlx \
  --summary-model unsloth/gemma-4-E4B-it-UD-MLX-4bit \
  --tts-provider omlx \
  --tts-model Kokoro-82M-bf16 \
  --message "Added a Settings install section with an Install app button that uses the browser PWA install prompt when available, plus installed/unavailable states and EN/PL translations."
```

You should hear a short spoken update generated by Kokoro.

## Troubleshooting

- If requests fail, check the service:
  ```bash
  brew services info omlx
  ```
- If a model is not found, make sure the model directory name matches the configured model name under `~/.omlx/models`.
- To restart oMLX after downloading models:
  ```bash
  brew services restart omlx
  ```
